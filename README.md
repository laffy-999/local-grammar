# local-grammar

Grammarly-style spelling and grammar checking for Logseq and Obsidian.
A small LLM running locally in the background does the checking, so your notes never leave your machine.

## Goal

- Fast, per-mistake suggestions with one-click fixes inside the editor.
- English and German, detected per block or paragraph.
- One shared checking engine with a Logseq plugin and an Obsidian plugin on top.
- Fully local: no account, no cloud service.
